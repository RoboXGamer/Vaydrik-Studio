# Vaydrik Studio — Photography Portfolio Website

Built as a freelance project for Vaydrik Studio. Production photography portfolio site with custom intro animations, gallery with image optimization, and brand design showcase.

## Features

- Custom intro animation sequence (tunnel expansion → black dot transition → content reveal)
- Gallery with animated grid reveal, image overlay mask, blur transitions
- Photography categories: Wedding, Product, Food, Clothing
- Brand design portfolio gallery
- Services section with process timeline
- Smooth scroll navigation, fade-in animations on scroll
- Responsive design, dark theme
- Session-based intro replay management

## Tech Stack

| Layer | Tech |
|---|---|
| Framework | Astro 5 |
| Image processing | Sharp |
| Animations | CSS transitions, Intersection Observer |
| Styling | Tailwind CSS |
| Deployment | Netlify |

## Setup

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
